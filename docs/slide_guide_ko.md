# 의학 발표 슬라이드 지침 (한 장)

이 파일과 `medsci_slides.pptx`를 Claude나 ChatGPT에 함께 첨부하고 이렇게 요청한다.

> 첨부한 지침을 따르고, 첨부한 템플릿의 레이아웃만 써서 발표 자료를 만들어 줘.
> 발표 종류: (학회 구연 8분 / 저널클럽 / 강의 30분 / 증례 발표)
> 청중: (같은 과 전문의 / 타과 의사 / 전공의·학생)
> 장마다 하고 싶은 말: (아래에 한두 문장씩. 주제만 줄 때는 근거로 쓸 논문이나 자료를 함께 첨부)

AI가 만든 초안은 70~80%라고 생각한다. 나머지는 발표자가 보고 고친다. "강조는 색으로", "이 표는 첫 열을 좁게"처럼 사람에게 시키듯 구체적으로 말하면 된다.

## 1. 한 장에 한 가지

- 한 장은 한 가지 주장만 한다. 두 가지면 두 장으로 나눈다.
- 제목은 주제어가 아니고 그 장의 결론을 문장으로 쓴다. "Results" 대신 "외부 검증에서도 정확도가 유지되었다". 제목은 한 줄에 들어가게 줄인다.
- 본문 글자는 24pt를 목표로 하고 20pt 아래로는 내리지 않는다. 안 들어가면 글을 줄이거나 장을 나눈다.
- 발표자가 말로 할 내용은 슬라이드에 쓰지 않고 발표자 노트에 쓴다.

## 2. 그림과 영상은 크게

- 그림·영상이 중심인 장은 그림이 슬라이드의 대부분을 차지하게 한다.
- 검게 보는 영상(CT, MRI, 혈관조영, 초음파)은 검은 바탕 레이아웃에 넣는다. 흰 바탕으로 그려진 그래프·도식·사진은 흰 레이아웃에 넣는다.
- 어디를 봐야 하는지는 화살표 하나와 짧은 라벨로 알린다.
- 표는 논문 화면을 캡처하지 않고 발표에 필요한 행과 열만 다시 그린다. 선은 세 개만 쓴다(머리글 위, 머리글 아래, 마지막 행 아래).
- 그래프는 코드(matplotlib, R)로 그려서 그림으로 넣는다. AI에게 도형으로 그래프를 그리게 하지 않는다.
- 글만 있는 장에는 연구 자료로 만든 작은 표나 그림 하나를 넣는다.

## 3. 강조와 색

- 강조는 굵은 글씨보다 색으로 한다. 한 장에 한두 구절만 색칠한다.
- 강조색은 둘까지 쓰고, 덱 전체에서 뜻을 고정한다. 첫째는 그 장의 핵심, 둘째는 비교 대상이다. 템플릿의 색 선택 창에서 강조 1과 강조 4가 그 두 색이다.
- 색만으로 뜻을 구분하지 않는다. 색각 이상이 있는 사람과 흑백 인쇄에서는 두 색이 비슷해 보인다.

## 4. 넣지 않는 것

AI가 만든 자료에서 반복해서 보이는 것들이다.

- 같은 모양의 상자가 장마다 반복되는 구성, 반투명 박스, 둥근 모서리, 그림자
- 큰 숫자 서너 개를 설명과 함께 한 줄로 늘어놓은 장
- 모든 장이 같은 틀인 구성(제목 + 불릿 세 줄 + 오른쪽 그림)
- 장마다 들어가는 로고, 긴 바닥글, 제목 위의 꾸밈 문구
- 아이콘과 내용이 없는 장식용 그림
- "지금부터 ~를 살펴보겠습니다", "요약하면", "핵심은" 같은 진행 안내 문장
- 뜻이 적혀 있지 않은 화살표. 화살표는 "원인이다", "다음 단계다" 같은 주장이다

섹션 이름을 적은 위쪽 띠는 발표자가 원하면 써도 된다. 평범한 슬라이드 디자인이다.

## 5. 의학 발표에서 지킬 것

- CT, MRI, 병리, 방사선 사진을 AI로 생성해 넣지 않는다. 설명용이어도 넣지 않는다.
- 환자 영상은 넣기 전에 이름·번호·날짜를 픽셀과 파일 정보에서 지운다. PowerPoint에서 자르거나 도형으로 가려도 원본은 파일 안에 남는다.
- 숫자에는 단위와 신뢰구간, 출처를 함께 쓴다.
- 남의 그림은 논문마다 라이선스를 확인하고, 슬라이드에 출처를 적는다(`Fig. 2b · 저자, 저널 연도`). 축, 범례, 좌우 표지가 잘리지 않게 자른다.
- AI가 쓴 문장은 인용한 논문이 실제로 그렇게 말했는지 원문과 대조한다. 좌우와 해부·임상 내용은 발표자가 직접 확인한다.
- 이해관계(COI)와 연구비는 Disclosure 장에 쓴다.
- 마지막 장은 "감사합니다"가 아니고 결론 한 줄이다. 질문 시간 내내 화면에 남는 장이다.

## 6. 템플릿에서 레이아웃 고르기

| 이 장이 할 일 | 레이아웃 |
|---|---|
| 핵심 결과를 숫자 하나로 | Key Finding |
| 연구 설계와 대상 | Study Design |
| 그림 하나로 결과를 | Result · Figure |
| 표로 결과를 | Result · Table |
| 두 가지를 비교 | Comparison |
| 한계 | Limitations |
| 가져갈 것 세 줄 | Take-home |
| 영상 한 장과 소견 | Imaging · Case |
| 영상 여러 장 | Imaging · 2×2, 1×3, 4 Steps |
| 영상을 화면 가득 | Imaging · Full |
| 문제와 답 | Imaging · Quiz |

템플릿에 없는 도형과 상자를 새로 그려 넣지 않는다.

## 7. 만든 뒤 확인

- 장 제목만 순서대로 읽어도 발표 내용이 이어지는가
- 글자가 틀 밖으로 넘치거나 겹치는 곳, 한 단어만 다음 줄로 넘어간 곳이 없는가
- 같은 틀이 세 장 넘게 이어지지 않는가
- 그림이 중심인 장에서 그림이 화면의 절반보다 큰가
- PowerPoint에서 직접 열어 한 번 넘겨 본다. AI가 "완성했다"고 해도 실제 화면은 다를 수 있다.

자료가 쉽게 만들어져도 준비에 드는 시간은 줄지 않는다. 줄어든 제작 시간은 내용을 공부하고 발표를 연습하는 데 쓴다.
